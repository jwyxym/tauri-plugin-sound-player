## Default Permission

Allows playing, stopping, pausing, resuming, and changing volume for sounds.

#### This default permission set includes the following:

- `allow-play-once`
- `allow-play-loop`
- `allow-stop`
- `allow-stop-all`
- `allow-set-volume`
- `allow-pause`
- `allow-resume`
- `allow-is-finished`
